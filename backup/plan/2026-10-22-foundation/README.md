## How To Use This Archive

This is a long-term reference, not a second active weekly schedule or an
automatically selected teaching workflow. Archived skill files are outside the
active repository-root `.github/skills` directory. Do not register the snapshot
as another skill search location.

The existing foundation remains valuable, but preservation is not endorsement
of every statement, test claim or historical deadline. Known review findings
remain relevant. Use selected topics later, following the active roadmap's
priorities and current source evidence.

Most internal relative links retain the original layout. Skills are preserved
separately under `backup/skills`, so their original relative plan links and
links from this snapshot to `.github/skills` are historical, not live navigation.
Links to sibling source
repositories were written for the original repository location and may not
resolve from this snapshot. Historical links may also reference files absent
from the current kernel branch. Do not change snapshot files to repair links;
consult the original learning workspace or the named historical revision.

No sibling source repositories, Git metadata, downloaded books, dependency
trees, generated binaries or employer material were copied. This archive does
contain personal learning and career records already present in the learning
repository. Review it before any public publication; creating it did not commit
or push it.

This in-repository snapshot is not an independent disk-failure backup.
